Des agents qui vous appartiennent, vraiment

Pas d'abonnement, pas de cloud imposé. Vos Locrits vivent sur votre machine et ne partagent que ce que vous décidez.

Local d'abord

Vos conversations restent chez vous

Les modèles tournent avec Ollama, les données sont enregistrées sur votre disque. La synchronisation Firebase existe, mais c'est vous qui l'activez.

Mémoire persistante

Un Locrit n'oublie pas

Messages, sessions, concepts : chaque Locrit garde sa propre mémoire d'une conversation à l'autre. Explorez-la, recherchez dedans, corrigez-la.

Permissions fines

Vous décidez qui parle à qui

Pour chaque Locrit : ouvert aux humains, aux autres Locrits, à Internet ? Accès aux logs, à la mémoire complète ? Une case à cocher par réponse.

Comment ça marche

Cinq étapes, de l'installation à la première conversation.

1

Installez Ollama

C'est lui qui fait tourner les modèles sur votre machine. Récupérez-en un avec ollama run llama3.2 : Locrits le détecte automatiquement.

2

Lancez Locrits

Une seule commande, ./start.sh, installe les dépendances puis démarre le backend et l'interface web. L'assistant de configuration vous accueille.

3

Créez votre premier Locrit

Un nom, une description de son rôle, un modèle Ollama. Expert technique, assistante de recherche, compagnon d'organisation : à vous de lui donner son caractère.

4

Réglez ses accès

Cochez ce qu'il a le droit de faire : parler aux humains, aux autres Locrits, accepter des invitations, lire les logs ou sa mémoire complète. Tout le reste lui est fermé.

5

Discutez, il s'en souviendra

Chaque échange enrichit sa mémoire. Demandez-lui de retenir un point précis, ou ouvrez l'explorateur pour voir — et corriger — ce qu'il a gardé.

Pour qui ?

Du premier essai d'IA locale à l'expérimentation multi-agents.

Pour découvrir l'IA locale

  • Aucun compte à créer
  • Assistant de configuration au premier lancement
  • Le modèle Ollama de votre choix
  • Thème clair ou sombre

Pour garder la main sur ses données

  • Conversations et mémoire stockées sur votre disque
  • Synchronisation cloud désactivée par défaut
  • Permissions réglées Locrit par Locrit
  • Mémoire consultable et effaçable à tout moment

Pour les développeurs

  • API REST et WebSocket
  • Backend Python modulaire, interface React + TypeScript
  • Moteurs de mémoire interchangeables : fichiers, graphe, vecteurs
  • Configuration lisible dans un simple fichier YAML

Pour explorer le multi-agents

Expérimental
  • Des Locrits ouverts aux autres Locrits
  • Adresse publique via tunnel SSH
  • Page publique propre à chaque Locrit
  • Recherche web intégrée via DuckDuckGo

Prêt à créer votre premier Locrit ?

Deux commandes, et il tourne chez vous. 

$ git clone https://github.com/poqudrof/Locrits.git
$ cd Locrits && ./start.sh
